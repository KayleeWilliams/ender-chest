## ender-chest@0.0.5

### Install Ender Chest from npm

Install the native CLI with `npm install --global ender-chest`. The package includes macOS and Linux binaries for ARM64 and x86-64, with no install scripts or extra downloads. npm releases use GitHub trusted publishing and include provenance.

Sync also supports Cursor, Meta Muse Code, Gemini CLI, and OpenCode v2. It preserves local agent settings and backs up existing instruction files. The starter config includes settings examples for all supported agents.
